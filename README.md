# OBORODUKI

[Verse 1]
水を張った庭に　月の輪がほどけ
眠れぬ窓辺で　君の名を呼んだ
白い息ひとつ　夜へ預けても
返事のかわりに　花びらが落ちる

[Pre-Chorus]
遠い季節の戸を　そっと押せば
あの日の横顔が　胸に差し込む

[Chorus]
朧月よ　君を照らして
帰る道を　見失わぬように
この手の中に　残った温度
抱いて明日へ　歩いてゆく

[Verse 2]
古い橋の上　川音を聞けば
交わした約束　今もほどけない
君が好きだった　薄紅の枝に
春を待つつぼみ　ひとつ揺れている

[Pre-Chorus]
別れの言葉を　風に渡して
それでも心は　君を覚えてる

[Chorus]
朧月よ　君を照らして
遠い空で　迷わぬように
胸の奥には　消えない灯り
抱いて明日へ　歩いてゆく

[Bridge]
涙のあとに　朝は来るだろう
君の笑顔を　連れてゆこう
この夜を越えて　名前を呼べば
新しい季節が　枝を満たす

[Final Chorus]
朧月よ　君を照らして
帰る道を　見失わぬように
いつか再び　会える日まで
この歌を胸に　歩いてゆく

[Outro]
水を張った庭に　月の輪がほどけ
君の名をそっと　夜へ返した
